# Code of conduct

## The short version

Be decent. This project is about other people's families, and a lot of the material it
handles belongs to someone who is elderly, or unwell, or no longer alive. Carry that
into how you talk to people here.

## What is expected

- Assume the person you are replying to is acting in good faith.
- Criticise the work, not the person who made it.
- Accept that people speak different languages and different amounts of English, and
  that a blunt sentence is often a translation, not an insult.
- Respect a decision once it has been made and recorded, or reopen it with a reason.

## What is not acceptable

- Harassment, insults, or sustained hostility, in issues, pull requests, commits, or
  anywhere else this project is discussed.
- Discriminatory language or imagery of any kind.
- Publishing anyone's private information without their explicit permission.
- Sharing, reposting or reusing family material encountered through this project.
  Anything you see because you contribute here is not yours to circulate.
- Sexualised language or attention in a project space.

## Scope

This applies in every repository in this organisation, in anything published from them,
and when representing the project elsewhere.

## Enforcement

Report a problem privately using GitHub's private vulnerability reporting on any
repository in the organisation, which reaches the maintainer without a public thread.
Reports are handled confidentially. Responses range from a private word to a permanent
ban, and the maintainer decides.

This is a one-person project. There is no committee, and the process is as informal as
that implies – but the standard is not.
