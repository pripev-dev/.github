# Support

Pripev is in development and has no customers yet, so there is no support desk to point
you at. Here is where things actually go.

| What | Where |
|---|---|
| A bug in code you can see | An issue on that repository |
| A question about how something is meant to work | A discussion, or an issue if the repository has none |
| A security or privacy problem | [SECURITY.md](SECURITY.md) – privately, never a public issue |
| Anything about a real family's recording | Privately, through the security route, whoever you are |

## Once there are customers

Routine questions – where a capsule is in processing, what a charge was for, how to
export or delete – are answered by a scoped support agent with narrow tools and no
access to family media.

Consent, ownership, bereavement, family disputes, takedowns, deletion disagreements and
anything involving a deceased person are **never** handled by an agent. They reach a
person, by design, and that will not be optimised away.

Response times will be published when they can be honoured. Publishing one now would be
a guess.
